## 六、退款政策与几个容易踩的坑

evoxt 给新用户 **7 天退款保证**，从部署第一台服务起算。但有几个条件会让保证失效，下单前最好心里有数：

- 服务已不在 "Active" 状态
- 该 VM 收到过滥用投诉
- 该 VM 的带宽使用率超过 20%
- VM 的 IP 被列入滥用数据库
- VM 的 IP 被政府防火墙拉黑

退款金额以 evoxt 实收金额为准，支付网关手续费不退。换句话说，**7 天试用期内别一上来就满带宽跑流量**，否则可能直接丧失退款资格。

另外几个常见踩坑点：

- **VM-0.5 / VM-0.75 用不了 40% 码**：这两个最低档只能用 `AFF809-ecscoupon` 之类的 5% 码。想拿 40% 折扣至少从 VM-1 起步。
- **优惠码是循环生效**：续费时只要码还在线，每月都自动打折，不用每月手动输入。
- **半年付 / 年付自动折扣与优惠码可叠加**：组合下来 VM-1 年付能压到 $3.23/月左右。
- **Premium 网络流量减半**：香港 / 大阪同价位流量只有标准网络的一半，跑大流量业务要算清楚。
- **退款期内别猛跑流量**：超过 20% 带宽使用率会失去退款资格。
